Objetivo General

Desarrollar un sitio web educativo denominado “Introducción a la Ofimática” que facilite el acceso a información clara, organizada y accesible sobre la ofimática y el uso básico de Microsoft Word, Excel y PowerPoint, fortaleciendo las competencias digitales de los usuarios.

Objetivos Específicos

✔

Organizar y estructurar contenidos educativos sobre ofimática y aplicaciones ofimáticas.

✔

Diseñar un sitio web con navegación sencilla, clara e intuitiva.

✔

Implementar el sitio utilizando tecnologías web como HTML, CSS y JavaScript.

✔

Incorporar imágenes, gráficos y recursos visuales con fines educativos.

✔

Integrar encuestas mediante Google Forms para apoyar el aprendizaje y análisis de conocimientos.
