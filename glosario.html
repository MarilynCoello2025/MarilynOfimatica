Glosario

  • ✔ Ofimática: Conjunto de herramientas informáticas para crear, editar y organizar información digital.
  • ✔ Aplicaciones Ofimáticas: Programas diseñados para facilitar tareas académicas y de oficina.
  • ✔ Microsoft Word: Programa utilizado para crear y dar formato a documentos de texto.
  • ✔ Microsoft Excel: Aplicación que permite organizar datos, realizar cálculos y crear tablas y gráficos.
  • ✔ Microsoft PowerPoint: Herramienta que sirve para crear presentaciones mediante diapositivas.
  • ✔ Documento: Archivo digital que contiene texto, imágenes u otros elementos informativos.
  • ✔ Hoja de cálculo: Archivo formado por filas y columnas que permite organizar información y hacer cálculos.
  • ✔ Diapositiva: Cada página que forma parte de una presentación en PowerPoint.
  • ✔ Interfaz: Parte visual de un programa o sitio web con la que interactúa el usuario.
  • ✔ HTML: Lenguaje que permite estructurar el contenido de un sitio web.
  • ✔ CSS: Lenguaje utilizado para diseñar y dar estilo visual a un sitio web.
  • ✔ JavaScript: Lenguaje de programación que agrega interactividad y dinamismo a un sitio web.
  • ✔ Sitio web: Conjunto de páginas web relacionadas que se pueden navegar por Internet.
  • ✔ Responsive: Característica de un sitio web que se adapta a distintos tamaños de pantalla.
  • ✔ Gráfica: Representación visual de datos que facilita la comprensión de la información.
  • ✔ Google Forms: Herramienta digital para crear encuestas y recopilar respuestas en línea.
  • ✔ Hosting: Servicio que permite almacenar y publicar un sitio web en Internet.
  • ✔ Netlify: Plataforma gratuita para publicar sitios web creados con HTML, CSS y JavaScript.
  • ✔ Pie de página (Footer): Parte inferior de un sitio web que muestra información adicional.
  • ✔ Visual Studio Code (VS Code): Editor de código utilizado para crear y editar archivos de programación web.
